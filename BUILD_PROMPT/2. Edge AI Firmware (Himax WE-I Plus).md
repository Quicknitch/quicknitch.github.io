You are an embedded AI engineer specializing in ultra-low-power neural network deployment
on microcontrollers.

Design the complete edge AI firmware for the Himax WE-I Plus co-processor inside Quicknitch.

Hardware:
- Himax WE-I Plus: ARMv7-M core @ 400MHz + hardware CNN accelerator (HW-AccAI)
- HM01B0 always-on QVGA camera (320x240, monochrome, 30fps, ~2mW)
- I2C slave interface to ESP32-S3 (results forwarded as structured messages)
- Total power budget: 5mW active inference, 0.8mW idle

Implement the following:

1. WAKE WORD DETECTION ENGINE
   - Model: Depthwise-separable CNN trained on 1-second audio windows
   - Input: 40 log-mel filterbank features, 98 time frames (1 second @ 16kHz)
   - Architecture: DS-CNN-S (from Keyword Spotting paper, Choi et al.)
     Layers: Conv2D(3x3, 64) → BN → ReLU → 4x [DWConv2D(3x3) + PWConv(64) + BN + ReLU]
     → GlobalAvgPool → Dense(10 classes)
   - Target: <50KB model size after INT8 quantization
   - False accept rate: <1/hour in typical home environment
   - Wake words: "Hey Nitch" (primary), "Quicknitch" (secondary)
   - Implement using TensorFlow Lite for Microcontrollers (TFLM) on ARM core
   - Audio input: PDM microphone data decimated to 16kHz PCM via software decimation filter
   - On positive detection: send I2C message to ESP32-S3 with confidence score

2. ALWAYS-ON PERSON DETECTION
   - Model: MobileNetV1 0.25x width, input 96x96 grayscale
   - Output: person_present (bool) + bounding box (normalized x,y,w,h)
   - INT8 quantized, target <80KB flash
   - Run at 5fps on HW-AccAI to stay within power budget
   - On person detected: send I2C message with bounding box to ESP32-S3
     for follow mode PID input
   - Person absence for >10 seconds: trigger "lost user" state

3. GESTURE RECOGNITION
   - Model: Temporal CNN over 15-frame optical flow windows (96x96)
   - Gestures: wave_hello, point_forward, thumbs_up, cross_arms_stop
   - 4-class softmax output, confidence threshold 0.85
   - Run only when person is detected and within 1.2m (signaled by ToF via I2C)
   - On gesture detected: send gesture_id + confidence to ESP32-S3

4. USER FACE ENROLLMENT AND RECOGNITION
   - Enrollment: capture 10 frames during onboarding, compute 128-dim FaceNet
     embedding (MobileFaceNet INT8) for each, store mean embedding in flash
   - Recognition: on each 2fps inference cycle while following, compute embedding
     of detected face, compute L2 distance to stored embedding
   - Match threshold: L2 < 0.75 = recognized owner, else "unknown person"
   - Send recognition result to ESP32-S3 every 500ms

5. SAFETY SCENE DETECTION
   - Lightweight 5-class CNN: safe_indoor, near_glass, staircase_detected,
     too_dark, outdoor_detected
   - Input: 64x64 grayscale, 3fps
   - If staircase or near_glass detected: send safety_alert to ESP32-S3
     which triggers slow-down and increased ToF sensitivity

6. FIRMWARE ARCHITECTURE
   - Bare-metal C on ARM core (no RTOS — interrupt-driven scheduler)
   - Inference pipeline: capture frame → pre-process → queue to HW-AccAI →
     collect result → post-process → I2C transmit
   - Double-buffered frame capture to avoid blocking
   - I2C slave interrupt handler with 16-byte message protocol:
     [0x51 header][msg_type][payload 12 bytes][CRC16]
   - Power management: gate HW-AccAI clock between inference runs
   - OTA model update: receive new .tflite model over I2C in 4KB chunks,
     verify SHA256, write to flash bank B, reboot to new model
