2. DEVELOPER API PLATFORM

   REST API (TypeScript + Fastify):
   Endpoints:
   POST   /v1/developer/register       — register developer account
   POST   /v1/developer/apps           — create app (returns client_id + secret)
   GET    /v1/devices/{id}/stream      — WebSocket upgrade for real-time data
   POST   /v1/devices/{id}/command     — send flight command
   GET    /v1/devices/{id}/telemetry   — last 24h telemetry
   POST   /v1/devices/{id}/speak       — trigger TTS on device
   GET    /v1/users/{id}/memory        — read memory (with user OAuth consent)
   POST   /v1/skills/submit            — submit skill for review

   WebSocket stream message types (JSON):
   {type: "camera_frame", data: base64_jpeg, timestamp: number}
   {type: "audio_chunk", data: base64_opus, timestamp: number}
   {type: "telemetry", battery: number, altitude: number, mode: string}
   {type: "gesture", gesture: string, confidence: number}
   {type: "transcript", text: string, speaker: "user"|"quicknitch"}

   Command message types:
   {type: "fly_to", x: number, y: number, z: number, speed: number}
   {type: "orbit", radius: number, speed: number, duration: number}
   {type: "hover"}
   {type: "land"}
   {type: "set_mode", mode: "follow"|"hover"|"orbit"|"perch"}

   Rate limiting: 100 commands/min (free), 1000/min (developer), unlimited (commercial)
   Authentication: OAuth2 with PKCE for user-scoped tokens, API keys for device-scoped
