You are a senior PCB design engineer specializing in dense mixed-signal boards
for consumer robotics.

Design the complete PCB for Quicknitch's main flight controller and AI board.

Constraints:
- Maximum board dimensions: 28mm diameter circular board
- Maximum total board + component height: 3.2mm (fits inside shell)
- 4-layer stackup: Signal | GND | PWR | Signal
- All SMT components, LGA/QFN/WLCSP packages only
- IPC-A-610 Class 2 assembly standard
- Operating temperature: 0–55°C
- Must survive 5g vibration (motor wash at 25kHz)

Components to place:
- ESP32-S3-WROOM-1 module (18x20mm — this is the largest component,
  will slightly overhang the circular board edge; design for this)
- Himax WE-I Plus (WLCSP, 2.5x2.5mm)
- ICM-42688-P IMU (3x3mm LGA) — isolate from motor vibration with
  0.5mm silicone pad under board at mounting points
- BMP388 barometer (2x2mm LGA) — needs pressure vent hole in shell,
  place near board edge
- PMW3901 optical flow (28-pin LCC, 16.5x16.5mm) — bottom of board,
  faces down through hole in shell
- OV2640 camera module (connected via 15-pin ZIF FFC cable, route ZIF
  connector to board edge)
- HM01B0 camera (5x5mm CSP) — connected to Himax WE-I Plus
- 8x DRV8837 motor drivers (8-pin USON, 2x2mm each)
- BQ25180 battery management IC (9-pin DSBGA, 1.6x1.6mm)
- 4x VL53L4CX ToF sensors (12-pin CLCC, 4.4x2.4mm each) — route 2 to
  board edge connectors for external sensor pods
- SPH0645LM4H x2 MEMS microphones (3.5x2.65mm, bottom-port)
- Supporting passives: ~150 components (resistors, capacitors, ferrites,
  crystals, LEDs)

Design requirements:

1. LAYER STACKUP AND IMPEDANCE
   - Layer 1 (Top): High-speed signals, RF keep-out around ESP32-S3 antenna
   - Layer 2: Solid ground plane, no cuts under switching regulators
   - Layer 3: Power planes (3.3V, 1.8V, battery rail), split as needed
   - Layer 4 (Bottom): Low-speed signals, motor drive PWM traces
   - Target controlled impedance: 50Ω single-ended, 100Ω differential
     for USB DP/DM traces
   - Specify board material: FR4 with Tg > 150°C, 1oz copper all layers

2. POWER DISTRIBUTION NETWORK
   - Battery input (3.0–4.2V) → BQ25180 → 3.3V LDO for digital rails
   - Separate 3.3V switching regulator for motor driver logic
   - 1.8V LDO for Himax WE-I Plus and camera
   - Motor driver power (VMOT): direct from battery through 10A-rated
     polygon pours, not traces
   - Bulk decoupling: 100µF X5R ceramic near battery input
   - Per-IC decoupling: 100nF + 10nF on every VDD pin within 0.3mm
   - Simulate PDN with target impedance < 50mΩ at 10MHz

3. RF DESIGN
   - ESP32-S3 PCB antenna: maintain 3mm keep-out on all layers
   - No copper, vias, or traces in antenna keep-out zone
   - Route all high-speed signals away from antenna region
   - Optional: UWB module (DWM3001C) footprint reserved on bottom
     layer with matching network placeholder

4. MOTOR DRIVE LAYOUT
   - 8x DRV8837 motor drivers arranged in 2 groups of 4 for coaxial
     and lateral motor groups
   - Motor current return paths: verify all high-current loops are minimized
   - PWM traces: 50mΩ max resistance, 100mA max current each
   - Add 0Ω series resistors on all PWM lines for EMI tuning
   - Snubber placement: 10nF + 10Ω across each motor connector

5. POGO PIN CHARGING INTERFACE
   - 3x pogo pin pads (GND, VBAT, DATA) on bottom of board
   - Pad size: 1.5mm diameter, gold-plated
   - Positioned at center, 3mm from board edge, 4mm apart
   - VBAT pad protected by P-channel MOSFET reverse polarity guard

6. MECHANICAL
   - 4x M1.4 mounting hole with 0.5mm annular ring, no copper on layer 2/3
   - Board outline: 28mm diameter circle + 2mm notch for shell alignment tab
   - Provide complete mechanical drawings in DXF format
   - Component height map: identify all components > 1.5mm for case
     clearance verification
   - Generate 3D STEP file for mechanical integration

7. DESIGN FOR MANUFACTURING (DFM)
   - Minimum trace width: 0.1mm (4mil), minimum clearance: 0.1mm
   - Minimum via: 0.2mm drill, 0.4mm pad
   - No via-in-pad unless plugged and plated
   - Stencil aperture rules: all QFN/LGA pads at 80% reduction
   - Panelization: V-score panel of 3x5 boards (15 per panel)
     for 200mm x 300mm PCB fab panel
   - Test points: every power rail, every I2C/SPI bus, UART0 debug

Deliver: complete KiCad 7.0 project files (schematic + layout), Gerbers,
drill files, BOM with LCSC part numbers, pick-and-place CSV, and DFM report.
