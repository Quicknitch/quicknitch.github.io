# Quicknitch — Himax WE-I Plus Edge AI Firmware

Complete bare-metal C firmware for the Himax WE-I Plus co-processor,
implementing five concurrent neural network inference pipelines within a
**5mW active / 0.8mW idle** power budget.

## System Architecture

### State Machine

```
                    ┌─────────────────────────────────────┐
                    │              IDLE                   │
                    │  Wake word: ON   Camera: 1fps        │
                    │  HW-AccAI: gated  PDM: always-on    │
                    └──────┬───────────────────────────────┘
         wake word │       │ person_detected
         detected  ▼       ▼
              ┌────────────────────┐
              │   PERSON_TRACK     │◄──── wake word re-triggers
              │  Person: 5fps      │
              │  Face:   2fps      │
              │  Safety: 3fps      │
              └──────┬─────────────┘
       ToF<1.2m  AND │gesture_enable_cmd
          ▼          │
    ┌──────────────┐ │
    │ GESTURE_SCAN │◄┘
    │ Gesture: 5fps│
    └──────┬───────┘
           │ person_absent > 10s
           ▼
    ┌─────────────┐      start_enroll_cmd
    │  LOST_USER  │─────────────────────►┌──────────────┐
    │ Person: 2fps│                      │  ENROLLING   │
    └─────────────┘                      │  10 frames   │
                                         └──────────────┘
                    ┌─────────────────────────────────────┐
                    │             OTA MODE                │
                    │  All inference suspended            │
                    │  I2C chunk reception only           │
                    └─────────────────────────────────────┘
```

### Inference Pipeline (per task)

```
Camera DMA ISR → g_frame_new flag
      │
      ▼
main loop task check (TASK_DUE?)
      │
      ▼
hal_camera_get_frame()    ← double buffer swap
      │
      ▼
pre-process (resize/crop/normalize)
      │
      ▼
hal_accai_run()           ← ungate clock → DMA → poll done → gate clock
      │
      ▼
decode output (dequantize, threshold, IIR)
      │
      ▼
build I2C message + CRC16
      │
      ▼
hal_i2c_send_msg()        ← copied to TX buffer, clocked out on master read
```

## Power Budget Analysis

| Component        | Active State       | Idle State    |
| ---------------- | ------------------ | ------------- |
| HM01B0 camera    | 2.0 mW (always)    | 0.2 mW        |
| PDM microphone   | 0.8 mW (always)    | 0.8 mW        |
| ARM core         | 1.2 mW @ inference | 0.1 mW (WFI)  |
| HW-AccAI         | 3.0 mW @ inference | 0 mW (gated)  |
| I2C + misc       | 0.2 mW             | 0.1 mW        |
| **Total active** | **~5.0 mW** ✓      |               |
| **Total idle**   |                    | **~0.8 mW** ✓ |

Power gating strategy:
- HW-AccAI clock gated between inference runs (HAL: `CLK_GATE` register)
- Camera throttled to 1fps in IDLE state
- ARM core uses WFI when no tasks are due
- PDM microphone stays on always (wake word monitoring requirement)

## I2C Protocol Quick Reference

All messages: **16 bytes** fixed length.

```
Byte  0     : 0x51 (magic header)
Byte  1     : msg_type
Bytes 2-13  : payload (12 bytes, type-specific)
Bytes 14-15 : CRC-16/CCITT-FALSE over bytes [0..13]
```

### Receiving a message on ESP32-S3 (Arduino/IDF example)

```cpp
#define WE1_ADDR  0x42
#define MSG_SIZE  16

uint8_t buf[MSG_SIZE];
Wire.requestFrom(WE1_ADDR, MSG_SIZE);
for (int i = 0; i < MSG_SIZE; i++) buf[i] = Wire.read();

// Validate
if (buf[0] != 0x51) return; // bad header
uint16_t crc_recv = buf[14] | (buf[15] << 8);
uint16_t crc_calc = crc16_ccitt(buf, 14);
if (crc_recv != crc_calc) return; // CRC mismatch

uint8_t msg_type = buf[1];
// Dispatch on msg_type...
```

### Sending an OTA chunk from ESP32-S3

```cpp
// 1. OTA_START
Wire.beginTransmission(WE1_ADDR);
Wire.write(0xA0);                    // OTA_START
Wire.write(model_id);
Wire.write((uint8_t*)&total_size, 4); // LE
Wire.write(sha256_hash, 32);
Wire.endTransmission();
delay(100); // wait for flash erase

// 2. OTA_CHUNK (repeat for each 4KB block)
Wire.beginTransmission(WE1_ADDR);
Wire.write(0xA1);
Wire.write(chunk_idx & 0xFF);
Wire.write(chunk_idx >> 8);
Wire.write(chunk_size & 0xFF);
Wire.write(chunk_size >> 8);
Wire.write(data, chunk_size);
Wire.endTransmission();
// Wait for OTA_ACK response before next chunk

// 3. OTA_COMMIT
Wire.beginTransmission(WE1_ADDR);
Wire.write(0xA2);
Wire.write(model_id);
Wire.write(0,0,0,0,0,0);
Wire.endTransmission();
// WE-I will SHA256-verify, copy to bank A, then reset
```

## Model Sizes and Flash Layout

| Model         | INT8 Size   | Flash Offset (Bank A) |
| ------------- | ----------- | --------------------- |
| Wake Word     | ~42 KB      | 0x08020000            |
| Person Detect | ~74 KB      | 0x0802A800            |
| Gesture       | ~58 KB      | 0x0803A800            |
| Face Recog    | ~88 KB      | 0x08048800            |
| Safety Scene  | ~44 KB      | 0x0805E000            |
| **Total**     | **~306 KB** | fits in 384KB bank    |

Face embedding: 512 bytes at 0x08081000 (config region)

## Build Instructions

```bash
# Prerequisites
export TFLM_ROOT=/path/to/tensorflow
arm-none-eabi-gcc --version   # >= 10.3

# Generate model C arrays (after training)
xxd -i wake_word_int8.tflite  > models/wake_word_model.c
xxd -i person_int8.tflite     > models/person_model.c
xxd -i gesture_int8.tflite    > models/gesture_model.c
xxd -i face_int8.tflite       > models/face_model.c
xxd -i safety_int8.tflite     > models/safety_model.c
# Rename arrays to g_wake_word_model, g_person_model, etc. in each .c file
# Add corresponding extern declarations in model .h files

# Build
make all

# Flash
make flash PORT=/dev/ttyUSB0
```
